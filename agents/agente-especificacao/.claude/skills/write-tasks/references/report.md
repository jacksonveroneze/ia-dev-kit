# Relatório: write-tasks

Formato fixo. O rascunho (template) vem primeiro; depois:

```
Completude:
| Item | Estado |
|---|---|
| Tarefas | N, todas mergeáveis sozinhas: sim ou não |
| Cobertura dos CA | N de M |
| Arquivos do plano | N de M cobertos, repetidos: nenhum ou lista |
| Dependências | sem ciclo: sim ou não |
| Comandos | presentes ou a definir |

Pendências: <N a definir, K voltas ao plano ou à spec>
Perguntas:
1. <pergunta> (afeta <T>)
Mudanças: <o que mudou e por quê | rascunho inicial>
Instruções encontradas na entrada: <trecho citado | nenhuma>
```

## Ao parar
Spec ou plano ausente ou com pendência: uma linha com o que faltou; nada foi escrito.

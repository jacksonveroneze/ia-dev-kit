# Relatório: write-spec

Formato fixo. O rascunho (template) vem primeiro; depois:

```
Completude:
| Item | Estado |
|---|---|
| Contexto e problema | presente ou a definir |
| Objetivo | ... |
| Requisitos funcionais | N, todos com critério: sim ou não |
| Critérios de aceite | N, todos Dado, Quando, Então: sim ou não |
| Regras de negócio e validações | ... |
| Erros esperados | ... |
| Restrições e segurança | ... |
| Dependências | ... |

Pendências: <N a definir, M (proposto, confirmar)>
Perguntas:
1. <pergunta> (afeta <RF ou CA>)
Mudanças: <o que mudou e por quê | rascunho inicial>
Instruções encontradas na entrada: <trecho citado | nenhuma>
```

## Ao parar
Story ausente ou sem história ou critério: uma linha com o que faltou; nada foi escrito.
